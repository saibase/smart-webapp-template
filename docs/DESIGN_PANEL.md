# 设计面板与工具栏需求文档

> 本文档描述编辑器「设计」模式下右侧属性检查器（PropsPanel）与画布工具栏的完整功能规范。

---

## 一、顶部全局操作区

位于编辑器顶部通栏，提供全局操作入口与工作流切换。

### 1.1 操作按钮

| 元素 | 类型 | 功能说明 |
|------|------|----------|
| `A?` | 图标按钮 | AI 辅助设计入口，一键生成 / 优化设计、智能补全界面 |
| `S` 头像 | 圆形头像 | 个人中心 / 账号设置入口 |
| 分享 | 文字按钮 | 一键分享设计稿，支持权限配置（可编辑 / 仅查看） |
| ▶ | 图标按钮 | 切换到原型预览模式，演示交互流程 |
| `49%` | 数值控件 | 画布缩放比例，点击快速切换 / 自定义倍率 |

### 1.2 工作流标签（三标签切换）

| 标签 | 状态 | 功能 |
|------|------|------|
| 设计 | 当前激活 | 图层属性编辑（本文档描述范围） |
| 原型 | 切换可用 | 交互跳转、动效配置 |
| 标注 | 切换可用 | 自动生成开发标注，导出切图 / 样式代码 |

**实现要点：**
- 缩放控件支持键盘输入与滚轮调整
- 标签切换时保留各模式的面板状态
- 分享功能弹出权限配置弹窗

## 二、对齐与位置参数区

### 2.1 对齐工具栏（8 个操作）

水平方向：左对齐 | 水平居中 | 右对齐 | 水平等距分布  
垂直方向：顶对齐 | 垂直居中 | 底对齐 | 垂直等距分布

**实现要点：**
- 单选时相对画布对齐；多选时相对选中组的包围框对齐
- 等距分布需至少选中 3 个元素才激活

### 2.2 位置 / 尺寸 / 变换控件

| 参数 | 字段 | 说明 |
|------|------|------|
| X | `position.x` | 相对画布原点的横坐标，精度 1px |
| Y | `position.y` | 相对画布原点的纵坐标，精度 1px |
| W | `props.style.width` | 图层宽度，支持等比缩放 |
| H | `props.style.height` | 图层高度，支持等比缩放 |
| 旋转 | `props.rotation` | 0°–360°，支持数值输入与拖拽 |
| 约束 | `props.constraints` | 固定 / 拉伸，控制父容器缩放时的适配规则 |

**实现要点：**
- W/H 旁有锁链图标，点击切换等比缩放模式
- 多选时显示包围框的整体尺寸，修改时等比缩放所有选中元素
- X/Y 输入支持 `+10`、`-5` 等增量表达式

### 2.3 圆角设置

- **统一圆角**：单个数值，4 角同步调整
- **多值圆角**：展开后独立设置左上、右上、右下、左下 4 个圆角
- 对应 `props.style.borderRadius`（统一）或 `borderTopLeftRadius` 等（分开）

## 三、布局与交互配置区

### 3.1 自动布局（Auto Layout）

给图层添加响应式布局，子元素自动间距、容器自适应内容。

| 参数 | 说明 |
|------|------|
| 方向 | 水平（Row）/ 垂直（Column） |
| 主轴间距 | 子元素之间的间距 |
| 内边距 | 容器四周内边距（上/右/下/左） |
| 对齐 | 9 宫格对齐方式选择 |
| 溢出 | 裁剪 / 滚动 / 可见 |

### 3.2 约束（Constraints）

控制图层在父容器缩放时的锚点行为：

- **水平**：靠左固定 / 靠右固定 / 居中固定 / 拉伸
- **垂直**：顶端固定 / 底端固定 / 居中固定 / 拉伸
- 可视化锚点图（3×3 网格图标）直观展示固定位置

### 3.3 固定行为（Scroll Behavior）

控制图层在滚动容器中的表现：

| 值 | 说明 |
|----|------|
| 随父级滚动 | 默认，随滚动条移动 |
| 吸顶固定 | 滚动时固定在容器顶部（`position: sticky` top） |
| 吸底固定 | 固定在容器底部 |
| 悬浮固定 | 始终悬浮（`position: fixed`），适用于导航栏、底部 Tab |

### 3.4 图层混合（Layer Blend）

| 参数 | 控件 | 说明 |
|------|------|------|
| 混合模式 | 下拉选择 | 穿透 / 正常 / 正片叠底 / 滤色 / 叠加 等 |
| 不透明度 | 数值 + 滑块 | 0–100%，对应 `opacity` |
| 可见性 | 眼睛图标 | 快速切换图层显隐（`props.visible`） |

## 四、视觉样式区

### 4.1 填充（Fill）

- **纯色**：色值输入 + 拾色器弹窗，`props.style.backgroundColor`
- **渐变**：线性 / 径向渐变，`props.style.background`
- **图片**：图片 URL，`props.style.backgroundImage`
- 支持多填充层叠（`+` 号添加，可拖拽排序）
- 多选且值不一致时显示「存在不同属性值」提示

### 4.2 描边（Stroke）

| 参数 | 控件 | 说明 |
|------|------|------|
| 颜色 | 色块 + 色值输入 | `props.style.borderColor` |
| 粗细 | 数值输入 | `props.style.borderWidth`（px） |
| 位置 | 分段控件 | 内部 / 居中 / 外部（CSS box-shadow 模拟） |

### 4.3 颜色选集（Color Palette）

- 展示当前文件全局色板（主色、辅色、中性色等）
- 点击色块一键应用到选中图层的填充/描边
- 支持编辑 / 新增 / 删除色板
- 色板数据存储在项目级配置中

## 五、拓展功能区

### 5.1 特效（Effects）

| 效果 | 参数 |
|------|------|
| 阴影 | X偏移 / Y偏移 / 模糊半径 / 扩展 / 颜色 / 透明度 |
| 内阴影 | 同上，向内渲染 |
| 高斯模糊 | 模糊半径 |
| 背景模糊 | 模糊半径（毛玻璃效果） |

对应 `props.style.boxShadow`、`filter`、`backdropFilter`。

### 5.2 导出（Export）

| 参数 | 说明 |
|------|------|
| 倍率 | 1x / 2x / 3x，生成不同分辨率切图 |
| 格式 | PNG / JPG / SVG / WebP |
| 命名 | 自定义导出文件名前缀 |
| 操作 | 点击「导出」按钮下载 |

## 九、交互流程

### 属性编辑流程
1. 用户在画布点击图层 → `selectedElementIds` 更新 → PropsPanel 读取选中图层数据
2. 用户修改属性 → 调用 `updateElementProps(id, changes)` → 画布实时预览更新
3. 多选时：对齐操作应用到所有选中图层，数值输入显示「混合值」提示

### 颜色选色流程
1. 点击色块 → 弹出拾色器面板（色轮 + 透明度滑块 + 色值输入）
2. 支持 HEX / RGB / HSL 三种格式切换
3. 确认后更新 `props.style.backgroundColor`（或 `borderColor`）

### 工具切换流程
1. 点击工具栏图标 / 按快捷键 → `setToolMode(...)` 更新当前工具
2. 画布根据 `toolMode` 切换鼠标事件行为（拖拽、绘制、平移）
3. 非选择工具时，PropsPanel 展示「请先用选择工具选中图层」提示
